## 零、本轮决策（2026-11-21 用户拍板）

| 决策 | 取值 | 理由 / 落地方式 |
|---|---|---|
| 面板刷新节奏 | **150ms**（≈7Hz） | 收支数字跳变更快对玩家无意义；面板整体从「每个绑定回调各刷一次」降为「每个收集窗口最多一次」 |
| 隐藏 UI / 照片模式 | **面板跟着消失** | 不再依赖原版 `.hide-ui` 后代选择器（我们 Portal 到 body，够不到）；用锚点可见性判定，并且**只暂时不渲染、`expanded` 保持 true**，退出照片模式自动回来 |
| 分类行溢出 | **截断成「+N」** | `pointer-events:none` 的面板无法滚动，宁可明确告知还有 N 项，也不做看不见的裁剪 |
| 「+N」文案 | **只显示数字** | 不带自带词条表，语言中立；要「+3 项」需额外词条方案，已关闭 |
| 数值量化再决定是否刷新（N4） | **做** | 已确认原版资金栏/经济面板对 money 单位只显示整数，所以小数位漂移不可能改变任何一个可见字符；raw 值照常保留，只是不触发重绘 |
| 清单落地 | 本文件 | 格式对齐 `StaticSceneryPloppables/docs/优化清单.md` |

## 五、坑位与结论（可复用）

- **Gameface 只转发 error 级别的 console 输出**：`console.log` 不进 Player.log，排障日志要用 `console.error`（且只留一条，避免每次加载刷一屏堆栈）。
- **`rem` 不是 html font-size**：CS2 的 `rem` 是随界面缩放的单位，`getComputedStyle` 读不到换算，只能用临时 probe 元素量 `width:100rem` 的像素宽再缓存（resize 失效重算）。
- **`.hide-ui` 挂在根节点、靠后代选择器隐藏**：body 直挂的 Portal 逃逸该机制，因此必须自己判定可见性，或把面板挂回原版 UI 子树。
- **面板 `pointer-events: none` = 不可滚动**：内容超高只能截断并明示 `+N`，不能指望滚动条。
- **原版禁用了 `filter` 类合成**：SSP 实测 `backdrop-filter` 掉 5–6 帧；本模组把 1px drop-shadow 换成描边，同源收益方向。
- **捆绑绑定回调不跨 task 批处理**：同一 tick 里多个 `ValueBinding` 回调各自触发 React 更新，必须自己做收集窗口。

## 七、发布后复审（2026-11-21）

对着 v1.0.2 的线上代码做了一次完整复审，回答「还有没有优化空间 / 过时注释 / 废弃代码 / 清单要不要更新」：

**结论**

1. **死代码：没有**。`tsc --noEmit --noUnusedLocals --noUnusedParameters` 只报工具链自带的 `types/validateTypes.ts`，我们自己的 12 个源文件零告警；逐个符号核对引用数，没有只声明不使用的函数/常量。
2. **过时注释：没有**。注释里 `no polling` / `cannot fail` / `rem` 换算 / `.hide-ui` 逃逸机制都仍与实际代码一致；README 里已无 `console.log`/`Host runtime` 之类旧描述。
3. **废弃代码：两处，已清**。`useAnchorState` 的恒真参数（+ 不可达分支）、`package.json` 里必失败的 `update`/`clean` 脚本；另外三个只在本文件内用的常量/函数收回私有。
4. **真正的优化空间：一处，已补**（N6）。宿主每次 push 都重建分类对象，引用比较让「同内容也算变化」成立，会把 N4 的量化收益吃掉 —— 结构比较修掉后，N4 才真正生效。
5. **清单确实需要更新**：A1/B3/C2 的「待重启验证」改为实测通过、补 N6/N7、补本节与发布记录、修正 mjs 体积与源文件数。
